# Symbols

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/laitouaigre/symbols.svg)](https://packagist.org/packages/laitouaigre/symbols) [![Total Downloads](https://img.shields.io/packagist/dt/laitouaigre/symbols.svg)](https://packagist.org/packages/laitouaigre/symbols)

A [Flarum](https://flarum.org) extension. Count symbols in the post message

## Installation

Install with composer:

```sh
composer require laitouaigre/symbols:"*"
```

## Updating

```sh
composer update laitouaigre/symbols:"*"
php flarum migrate
php flarum cache:clear
```
